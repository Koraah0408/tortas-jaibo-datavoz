# Encuesta de utilidad para el cliente (criterio «Utilidad para el cliente ≥ 4/5»)

**Cómo aplicarla:** sesión de 20–30 minutos con el dueño de la tienda (presencial o videollamada). El dueño usa
DataVoz con los datos de ejemplo haciendo al menos 5 preguntas propias (por texto o voz). Al final responde la
encuesta. Si el cliente no está disponible, un compañero actúa como usuario de prueba y se indica en el reporte.
